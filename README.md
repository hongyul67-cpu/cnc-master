### 화면

1. **📖 배우기** — 단원별로 접히는 개념 카드. 정답을 다 보여 주는 단계라 제일 앞에 둡니다.
   1단원 CNC 개요 / 2단원 제어 시스템 / 3단원 프로그램의 구성 / 4단원 절삭조건 /
   5~7단원 CNC 선반(좌표계·보간·사이클) / 8~10단원 머시닝센터(평면·보정·고정사이클) /
   11단원 CAD·CAM 과 DNC / 12단원 측정과 검사 / 13단원 판금 가공
2. **📇 G·M 코드 도감** — 선반 41 · 머시닝센터 55 · 공통 M코드 12. 기계로 거르고 글자로 찾습니다.
   **같은 번호인데 기계에 따라 뜻이 다른 코드**(G90 · G92 · G98 · G99 …)를 나란히 볼 수 있게 만든 화면입니다.
3. **🎮 게임 3종**
   - 🎯 코드 맞히기 — 도감에서 문제를 매번 새로 만듭니다(20문항). 오답은 같은 기계 안에서만 뽑습니다.
   - 🧮 절삭조건 계산 — `N = 1000V/(πD)` · `V = πDN/1000` · `F = f_z·Z·N` 세 가지를 숫자를 바꿔 가며 냅니다(8문항).
   - 🧩 프로그램 조립 — 뒤섞인 블록을 가공 순서대로 놓습니다. 줄마다 무엇을 하는 줄인지 설명이 붙습니다.
4. **✏️ 연습 8문항 / 🏁 종합시험 20문항 / 📕 오답노트**
5. **📽️ 전자칠판** — 선생님이 앞에서 끌고 가는 슬라이드 **126장**. 단원을 골라 들어가거나 처음부터 이어서 봅니다.

   | 단원 | 장수 | 내용 |
   |---|---|---|
   | 📌 코드를 읽기 전에 | 6 | 블록·워드, 모달과 원샷, 이송(G98·G99 ↔ G94·G95), 주축(G96·G97), 보정(G41·G42 → G40) |
   | ⚠️ 같은 번호, 다른 뜻 | 9 | **두 기계에 같은 번호가 25 개, 그중 8 개는 하는 일이 완전히 다릅니다** — G73 · G74 · G76 · G90 · G92 · G94 · G98 · G99 를 한 장에 하나씩 나란히 |
   | 🔧 CNC 선반 G코드 | 42 | 코드 41 개 + 안내 1 장 |
   | 🏭 머시닝센터 G코드 | 56 | 코드 55 개 + 안내 1 장 |
   | 🔩 공통 M코드 | 13 | 코드 12 개 + 안내 1 장 |

   **코드 슬라이드는 제목에 번호만 있습니다.** 뜻은 요점 안 <b>파란 빈칸</b>에 숨겨 두었고, 눌러야 열립니다 —
   학생에게 먼저 물어보라는 뜻입니다. 넘기기는 `[◀] [다음] [▶]` 단추와 `← →` 키만 듣습니다(수업 중 오작동 방지).

제출은 다섯 갈래로 갈립니다 — 연습 · 종합시험 · 코드 맞히기 · 절삭조건 계산 · 프로그램 조립.

## 고칠 곳

`index.html` 위쪽의 네 배열만 고치면 됩니다. 그 아래 코드는 대개 건드리지 않습니다.

| 배열 | 내용 |
|---|---|
| `LEARN` | 배우기 개념 카드 (`unit` 이 같은 것끼리 한 단원으로 묶입니다) |
| `CODES` | G·M 코드 도감 · 코드 맞히기 게임의 문제 원천 |
| `PROGRAMS` | 프로그램 조립 게임의 프로그램 (줄마다 `['블록', '설명']`) |
| `QUESTIONS` | 연습·종합시험 문항 |

> **전자칠판의 코드 슬라이드는 따로 고치지 않습니다.** `lesson.js` 가 `CODES` 를 그대로 읽어
> 코드 하나에 슬라이드 한 장을 만듭니다. 도감에 코드를 더하면 칠판에도 저절로 생깁니다.
> 그래서 `lesson.js` 는 반드시 `index.html` 의 인라인 `<script>` **뒤에** 붙어 있어야 합니다.
> 손으로 적는 것은 앞쪽 두 단원(「코드를 읽기 전에」·「같은 번호, 다른 뜻」)뿐입니다.

> **`QUESTIONS` 는 정답을 늘 `a:0` 에 두고 씁니다.** 화면에 낼 때 `prepQ()` 가 보기를 섞고
> 정답 번호를 다시 매기므로, 문항을 더할 때도 정답을 첫 보기에 두면 됩니다.
